# 19.08.2026 ver. 3.0

- Создан отдельный `.sln` файл для `Visual Studio 2022`, для удобного редактирования форм
- Добавлено отдельное указание в UI папки с `DLL` `Freelancer` которые требуются при импорте XML, а также процесс автоматического сохранения и загрузки заданной папки
- Исправлены функции экспорта XML
  - Добавлены санитайзеры (`SanitizeInlineString`) для нестандартных `.cmp` моделей
  - Добавлены санитайзеры (`SanitizeInlineString`) в конфигуратор записей о наличии `.dds` `.tga` в XML
- Исправлена функция `ftoa` обработки `float` значений на более `безопасную` версию, которая не вызывает больше ошибок при чтении `utf`
- Добавлены кнопки выбора папок `импорта` и `экспорта` `XML`
- Обновлены соавторы, добавлены первые создатали из `.rc` файлов в основное `README.md`
- Добавлен стартап для `Visual Code` под отладку кода
- Добавлена поддержка сборки на `Visual Studio 2022`
  - Исправлена часть кода для совместимости
- Добавлен сборочный скрипт [`build.bat`](build.bat)
- Изменён процесс выбора папки с игрой на современный вариант выбора папки через `FileInfo`
- Исправлены процессы чтения `.utf` файлов на `unsigned char`
- Добавлено авторство и обновлена версия приложения до `3.0.0`
- Автор: **Dvurechensky**

## 2010 ver. 2.2

- Утилита продолжает работу даже если установка Freelancer не обнаружена

- Переименованы комментарии `VMeshRef`
- Для значений Frames в частях `Pris` больше не используется преобразование в градусы
- Добавлено преобразование quaternion → angle/axis при использовании Rotation
- Добавлена поддержка аргументов командной строки
- Итоговая статистика конвертации добавляется в лог
- Добавлено создание полного пути назначения
- Лог временно записывается в системную временную директорию
- Из атрибута `path` удаляется префикс `DATA\`
- Автор: **Jason Hood**

## 2010 ver. 2.1

## 2010 ver. 2.0

- Утилита больше не закрывается автоматически после завершения работы
- Исправлено получение пути назначения из реестра
- Добавлено создание конечной директории назначения
- Расширена поддержка регистронезависимых сравнений
- Добавлена возможность выбирать конкретное расширение UTF-файлов
- Поля `Unk4` и `Unk5` заголовка объединены в единое значение `FILETIME`
- `Unk234` интерпретируются как DOS-style дата и время файла
- `Unk234` добавляются только если отличаются от родительского узла и включена опция timestamp
- Добавлена обработка почти всех известных типов узлов
- Извлекаемые файлы теперь сохраняются в отдельную поддиректорию
- Убрана необходимость добавлять CRC к имени извлечённого файла
- Удалены отдельные опции извлечения `VMeshData` и `VWireData`
- `VMeshData` и `VWireData` объединены в общую опцию `Include Files`
- Добавлено сканирование audio INI-файлов для получения имён `msg`
- Добавлено сканирование определённых UTF-файлов для получения имён материалов вместо CRC
- Улучшен интерфейс программы
- Автор: **Jason Hood**

## 2004 ver. 1.1

- Исправлена ошибка, о которой сообщил **Eirik Sletteberg**
- Удалены лишние запятые после атрибутов `unk`
- Исправлена ошибка, из-за которой исчезали головы и кисти персонажей
- Удалена логика, заменявшая отрицательные значения `Orientation` на `0`
- Добавлен узел `<UTF_ROOT>...</UTF_ROOT>` для сохранения неизвестных значений
- Добавлены дополнительные атрибуты в тег `UTFXML` для повышения соответствия файлов, создаваемых XMLUTF, оригинальным UTF-файлам
- Добавлена поддержка следующих атрибутов:
  - `dupstrings`
  - `prepaddata`
  - `string_padding`
  - `nodes`
  - `ssize`
  - `salloc`
  - `doffset`
  - `original_size`
  - `padding="4"`
- После тестирования установлено, что Freelancer корректно работает и без этих атрибутов, поэтому они были закомментированы
- Если все три неизвестных значения совпадают, используется один атрибут `unk234`
- Значения `unk` добавляются только если они отличаются от `0`
- Автор: **Sir Lancelot**
